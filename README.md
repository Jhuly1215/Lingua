# LINGUA

**Plataforma Computacional para la Investigación y Caracterización del Lenguaje en Personas con Afasia**

LINGUA es una plataforma orientada a la investigación y apoyo a la evaluación clínica profesional. Permite registrar pacientes, organizar información clínica autorizada, administrar evaluaciones neuropsicológicas del lenguaje (como la Fluencia Verbal FAS) y, en fases posteriores, procesar grabaciones y características lingüísticas mediante servicios de inteligencia artificial.

> **Aviso clínico y ético:** LINGUA está concebida como herramienta de investigación y apoyo profesional. No emite diagnósticos clínicos autónomos ni sustituye el criterio médico ni fonoaudiológico.
